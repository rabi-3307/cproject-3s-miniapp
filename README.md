# じゃんけんRPG

じゃんけんで敵と戦い、レベルを上げながら魔王を目指すコンソールゲームです（C++）。

授業で扱った「1回だけじゃんけんをする基本プログラム」をもとに、自分で機能を拡張して作りました。

## 遊び方

- 敵が順番に登場します。`G`（グー）、`C`（チョキ）、`P`（パー）を入力して、じゃんけんで戦います。
- 勝つと敵にダメージを与え、負けるとプレイヤーがダメージを受けます。あいこはダメージなしです。
- 敵を倒すと経験値が入り、レベルが上がると最大HPが増えて回復します。
- `Q` を入力すると、戦闘から逃げてゲームを中断できます。
- スライム、ゴブリン、オークを倒すと、最後にボス「魔王ジャンケロス」が登場します。

## ビルドと実行

`g++` があれば、次のコマンドでビルドできます。

```
g++ janken_rpg.cpp -o janken_rpg
./janken_rpg
```

Windowsでは `janken_rpg.exe` が作られます。日本語が文字化けする場合は、ターミナルで `chcp 65001` を実行してから起動してください。

## 元のプログラムから拡張した点

元のプログラムは、`if` 文だけで1回勝負を判定するものでした。次の点を追加・変更しました。

- **クラス化**: `Player`（HP、レベル、経験値）と `Enemy`（名前、HP、攻撃力、手の選択）に分けて管理
- **継承とポリモーフィズム**: `Boss` が `Enemy` を継承し、`chooseHand()` を上書きして特殊な行動を実装。ボスはHPが減ると行動パターンが変わり、パーを出しやすくなる
- **STL**: `vector<Enemy*>` で敵の一覧を管理し、順番に戦う
- **関数の分離**: 手の選択、勝敗判定、結果の表示を、独立した関数にまとめた
- **ゲームの流れ**: 複数の敵との連戦、経験値とレベルアップ、ボス戦、ゲームオーバーとクリアの判定を追加
- **メモリ管理**: 確保した敵のオブジェクトを、最後に `delete` で解放

## 使っている技術

- C++（クラス、継承、仮想関数、STLの `vector`）
- VS Code / g++（MinGW-w64）
